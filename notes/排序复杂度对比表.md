# 排序复杂度对比表

> 2026-09-11 整理。六个排序的时间/空间/稳定性，面试必背。

## 一、总表

| 排序 | 最好 | 平均 | 最坏 | 空间 | 稳定性 |
|---|---|---|---|---|---|
| 冒泡 | **O(n)**（加提前退出） | O(n²) | O(n²) | O(1) | ✅ 稳定 |
| 选择 | O(n²) | O(n²) | O(n²) | O(1) | ❌ 不稳定 |
| 插入 | **O(n)**（近乎有序时） | O(n²) | O(n²) | O(1) | ✅ 稳定 |
| 快速排序 | O(n log n) | O(n log n) | **O(n²)** | O(log n) 递归栈 | ❌ 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | **O(n log n)** | **O(n)** 额外数组 | ✅ 稳定 |
| 堆排序 | O(n log n) | O(n log n) | **O(n log n)** | **O(1)** 原地 | ❌ 不稳定 |

## 二、背诵要点（面试爱问的对比）

1. **只有冒泡、插入有"最好 O(n)"**——它们能提前发现"已经有序"
2. **只有快排最坏会退化到 O(n²)**（pivot 每次都选到极端值，如对已有序数组取首元素做 pivot）
3. **归并、堆排序：最坏也保证 O(n log n)**——追求"稳定输出"时的选择
4. **空间对比**：
   - 归并：O(n)（唯一需要大额外空间）
   - 快排：O(log n)（递归调用栈）
   - 堆排序：O(1)（完全原地，最省空间）
5. **稳定性**：稳定 = 冒泡、插入、归并；不稳定 = 选择、快排、堆

## 三、记忆口诀

> **"冒插归稳，选快堆不稳"**

**为什么这几个稳定？** 稳定的排序靠"**相邻交换**"或"**按顺序取用**"实现；一旦有"远距离跨越交换"（选择排序的整段交换、快排的 pivot 交换），相等元素的相对顺序就可能被打乱。

## 四、各排序核心一句话

| 排序 | 一句话 |
|---|---|
| 冒泡 | 相邻两两比，大的往后"冒"，每轮定一个最大值 |
| 选择 | 每轮找"剩余里最小的"，换到最前面（比较多、交换少）|
| 插入 | 摸牌式：新元素插进"已排好"的部分（移位实现）|
| 快排 | 选 pivot → 小的左大的右 → 左右递归（分治）|
| 归并 | 对半切 → 递归 → **合并两个有序段**（分治）|
| 堆排序 | 建大顶堆 → 反复"堆顶扔末尾 + 下沉"（原地）|

## 五、易错点归档（这三天踩过的坑）

| 排序 | 坑 | 正确做法 |
|---|---|---|
| 快排 | **相等元素导致指针死锁**（`>` / `<` 遇到等于 pivot 的值时两边都不动）| 比较用 `>=` / `<=`，让指针越过相等值 |
| 归并 | ① `temp[k]` 漏了 `k++` ② 扫尾放在主循环里用 `==` 判断 ③ 拷回从 0 开始 | ① `temp[k++]=arr[i++]` ② 主循环后两个独立 while ③ 只拷 `[low, high]` |
| 归并 | 稳定性开关：`<=` 才是稳定（相等先取左边）| `if(arr[i] <= arr[j])` |
| 堆排序 | 建堆必须**从最后一个非叶节点倒着往前**（`i = n/2-1 → 0`）| 自底向上：处理 i 时它的子树已是堆 |
| 堆排序 | 交换堆顶与末尾后，**下沉的 size 要缩小** | `sift_down(arr, end, 0)` |
| 堆排序 | 升序用**大顶堆**（每次把最大扔到末尾）| 小顶堆会排出降序 |
