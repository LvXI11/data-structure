## 一、归并排序：分治三步

**分** → 从中间切两半（不用像快排那样挑 pivot）
**治** → 左右两半各自递归排好
**合** → **合并两个有序段**（归并的难点，也是它和快排唯一的大区别）

```c
void merge_sort(int arr[], int temp[], int low, int high){
    if(low >= high) return;                          // 出口：一个元素天然有序
    int mid = (low + high) / 2;
    merge_sort(arr, temp, low, mid);                 // 左半排好
    merge_sort(arr, temp, mid+1, high);              // 右半排好
    merge(arr, temp, low, mid, high);                // 合（关键）
}
```

## 二、merge 函数模板（数组版"合并两个有序链表"）

```c
void merge(int arr[], int temp[], int low, int mid, int high){
    int i = low, j = mid+1, k = low;                 // ③ 三个指针
    while(i <= mid && j <= high){                    // ① 两边都没走完：取小的
        if(arr[i] <= arr[j]) temp[k++] = arr[i++];   //    <= 决定"稳定性"
        else                 temp[k++] = arr[j++];
    }
    while(i <= mid)  temp[k++] = arr[i++];           // ② 左半扫尾
    while(j <= high) temp[k++] = arr[j++];           //    右半扫尾
    for(int t = low; t <= high; t++) arr[t] = temp[t];  // ③ 只拷回这一段
}
```

**三个指针的含义**：`i` 扫左段、`j` 扫右段、`k` 是"写指针"（往 temp 写到哪里）。

**扫尾的本质**：主循环退出 ⇒ **必有一边先走完**；剩下那一半的残余元素都比已搬的大，按原顺序整体搬进 temp 即可。（没剩的那个 while 条件为假，循环体一次不执行）

## 三、当天踩的 3 个 bug（记住它们）

| Bug | 错误写法 | 正确写法 | 教训 |
|---|---|---|---|
| ① 漏写推进 | `temp[k]=arr[i++]` | `temp[k++]=arr[i++]` | **"漏写推进语句"家族第三次**（i++ 漏、k++ 漏） |
| ② 扫尾位置错 | 塞在主循环里 + 用 `==` 判断 | 主循环后两个独立 while | `==` 太脆（跳过就永不触发）；扫尾必须放循环外 |
| ③ 拷回范围错 | `for(i=0;i<=high;i++)` | `for(t=low;t<=high;t++)` | 只拷回**本次合并的 [low,high]**，从 0 拷会破坏别的段 |

## 四、指针传参（今天的重点理解）

### 4.1 参数是"副本"——C 只有值传递

```c
void f(int arr[]){ ... }      // 等价于 void f(int* arr)
```
- 传进来的 `arr` 是**局部变量**，保存"外面数组首地址的**副本**"
- 所以：**能改 `arr[i]`**（同一块内存，改的是那片空间里的值）
- 但：**不能改 `arr` 本身**（让局部副本指向别处，外面的数组名/指针没变）

### 4.2 想改"指针本身"要传指针的地址

```c
void f(int** p){ *p = ...; }   // 传 &p 才能改 p 指向哪
```
**但注意**：数组内容的搬运**不能靠改指针指向**！

```c
arr = temp;    // ❌ 双重无效：
               //    ① arr 是局部副本，赋值只改副本
               //    ② 就算用 int** 改了指针，也只是换个"标签"，
               //       调用方数组的内容一个字都没变
```

**正确姿势**：逐元素拷贝（或 `memcpy`）——这就是 `for(t=low;t<=high;t++) arr[t]=temp[t];` 存在的理由。

## 五、归并 vs 快排（对照记忆）

| | 快排 | 归并 |
|---|---|---|
| 分 | 选 pivot，小的左大的右 | 直接对半切 |
| 合 | 不用合 | **必须合**（合并两个有序段）|
| 平均 | O(n log n) | O(n log n) |
| 最坏 | O(n²)（pivot 选得极端差）| O(n log n)（稳定）|
| 额外空间 | O(log n)（递归栈）| **O(n)**（temp 数组）|
| 稳定性 | 不稳定 | **稳定**（相等时先取左边）|
| 关键坑 | 相等元素要用 `>=` / `<=`，否则指针死锁 | `k++` 别漏、扫尾放循环外、只拷回 [low,high] |
