排序

| 排序    | 最好       | 平均       | 最坏       | 空间      | 稳定  |
| ----- | -------- | -------- | -------- | ------- | --- |
| 冒泡    | O(n)     | O(n^2)   | O(n^2)   | O(1)    | 稳定  |
| 选择    | O(n^2)   | O(n^2)   | O(n^2)   | O(1)    | 不稳定 |
| 插入    | O(n)     | O(n^2)   | O(n^2)   | O(1)    | 稳定  |
| 希尔    | O(nlogn) | O(n^1.3) | O(n^2)   | O(1)    | 不稳定 |
| 快排    | O(nlogn) | O(nlogn) | O(n^2)   | O(logn) | 不稳定 |
| 归并    | O(nlogn) | O(nlogn) | O(nlogn) | O(n)    | 稳定  |
| 堆排序   | O(nlogn) | O(nlogn) | O(nlogn) | O(1)    | 不稳定 |
| 计数·基数 | O(n+k)   | O(n+k)   | O(n+k)   | O(n+k)  | 稳定  |

图论

| 算法       | 用什么存 | 时间       | 空间     |
| -------- | ---- | -------- | ------ |
| DFS      | 邻接表  | O(n+e)   | O(n)   |
| BFS      | 邻接表  | O(n+e)   | O(n)   |
| Prim     | 邻接矩阵 | O(n^2)   | O(n)   |
| Kruskal  | 边集数组 | O(eloge) | O(n+e) |
| 拓扑排序     | 邻接表  | O(n+e)   | O(n)   |
| Dijkstra | 邻接矩阵 | O(n^2)   | O(n)   |
Prim和Dijkstra用邻接表+堆 能到O(elogn)

查找

| 查找  | 平均      | 最坏        | 要求          |
| --- | ------- | --------- | ----------- |
| 顺序  | O(n)    | O(n)      | 无要求         |
| 二分  | O(logn) | O(logn)   | **必须有序**    |
| BST | O(logn) | O(n)退化为链表 | 有序性由中序保证    |
| 散列表 | O(1)    | O(n)全撞一列  | 好的散列函数+填装因子 |
