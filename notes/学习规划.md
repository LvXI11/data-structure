# 自学总规划：数据结构 + Java（按"学完"规划，不绑学校日历）

> 背景：软件工程准大二。**学校教得少，基本靠自学**——本计划不参考学校进度，按"学完数据结构"为第一个里程碑规划。
> 每天 **DS 3h + Java 2h（共 5h）**；节奏原则：**不紧**（每个结构都配复习日/默写，避免学得不熟或漏知识）、**不长**（DS 约 16 天收官，之后 3h 时段转 MySQL/JavaWeb，Java 2h 持续到 JavaSE 学完）。
> 目标锚点：**大二暑假找实习（Java 方向）**。

## 三、数据结构路线（3h/天，约 16 天收官）

> 每天结构：画图 40min → 写代码 1.5h → 复习+默写 50min。每 3-4 天一个复习日。

| 天数 | 内容 | 完成标准 |
|---|---|---|
| 第 1 天 | **队列**：循环队列（数组，先想"为什么浪费"）+ 链式队列 | 两种实现跑通 |
| 第 2 天 | 队列实战：**用两个栈实现队列** + 用队列实现栈；栈/队列对比总结 | 两题跑通 + 对比表 |
| 第 3 天 | **复习日①**：默写约瑟夫环 + 括号匹配 + 队列；LeetCode：有效括号、最小栈 | 默写对照无大错 |
| 第 4 天 | **二叉树入门**：概念/性质 + 前中后序遍历（递归，画图理解"自己调用自己"） | 三种遍历手写 |
| 第 5 天 | 二叉树进阶：非递归遍历（栈模拟）+ 层序遍历 + 求树高/节点数/叶子数 | 全部跑通 |
| 第 6 天 | 树经典题：重建二叉树、镜像二叉树 + LeetCode 简单树题 3-4 道 | 每题跑通 |
| 第 7 天 | **二叉搜索树**：插入/查找/删除 + 中序遍历的有序性 + 验证 BST | 增删查跑通 |
| 第 8 天 | **堆与优先队列**：概念 + 建堆/上浮下沉调整 | 建堆代码跑通 |
| 第 9 天 | **复习日②**：树专题默写（遍历/求高/查找）+ 错题回炉 | 默写对照 |
| 第 10 天 | 排序（上）：冒泡/选择/插入 复习 + **快速排序**（分治思想） | 快排跑通 |
| 第 11 天 | 排序（下）：**归并排序** + 堆排序 + 复杂度/稳定性对比表 | 归并跑通 + 表格默写 |
| 第 12 天 | **图**：存储（邻接矩阵 vs 邻接表）+ BFS/DFS（画图 + 代码） | 两种存储 + 遍历跑通 |
| 第 13 天 | 图进阶 + 查找：Dijkstra（概念）、拓扑排序（概念）、二分查找 | 概念图 + 二分代码 |
| 第 14 天 | **哈希表/散列**：散列函数 + 冲突处理（链地址/开放定址）——为 Java HashMap 埋伏笔 | 概念图 + 简单实现 |
| 第 15 天 | **复习日③**：排序默写（快排/归并）+ 图/哈希概念图 + 全部自查清单过一遍 | 默写对照 |
| 第 16 天 | **LeetCode 专项 + 自测小项目**：链表/栈/队列/树/排序各 1-2 题；小项目（浏览器前进后退 或 后缀表达式计算器） | 项目跑通 = **数据结构毕业** |

**毕业验收标准**：能合上资料默写出——链表/栈/队列/树/图的核心操作、快排/归并、BFS/DFS；LeetCode 累计约 30 题。

## 四、Java 路线（2h/天，宋红康课程，约 3-4 个月学完 JavaSE）

### 每天 2h 的固定结构（雷打不动）
- **前 50 分钟**：看视频（1.25–1.5 倍速，跳过"唠嗑/演示 IDE 操作"）
- **后 70 分钟**：把视频里的例子**自己敲一遍**（不复制粘贴），敲完跑通
- 规则：**视频只是入口，敲代码才是学习**。只看不敲 = 白看

### 课程精简路线
| 阶段 | 内容 | 预计（2h/天） | 说明 |
|---|---|---|---|
| 1 | 基础语法（环境、变量、运算符、流程控制、数组） | 2 周 | 和 C 语法 80% 相通，倍速看 |
| 2 | **面向对象（重点）**：类与对象、封装/继承/多态、接口、内部类 | 4–5 周 | 面试必考，节奏放慢，每题都敲 |
| 3 | 常用类（String、包装类）+ 异常处理 | 1.5–2 周 | String 是面试高频 |
| 4 | **集合框架**（List/Set/Map、迭代器、泛型） | 2–3 周 | 实习面试重灾区；学 HashMap 时回看 DS 哈希思想（两门课在此汇合） |
| 5 | IO 流 + 多线程（基础） | 2–3 周 | 多线程重点在概念和 synchronized，别深钻并发 |
| 6 | 网络编程、反射、JDK17 新特性 | 2 周 | 学不完可留到寒假 |

**关键里程碑**：阶段 2（OOP）学完 → **立刻用 Java 重写链表/栈/队列**（正好 DS 也已毕业，双线在此汇合）。

## 七、效率规则（踩过的坑换来的，写死在这里）

1. **卡壳时间盒**：卡住先自己想 20–30 分钟（画图、加打印、加注释、重读代码），超时再问 AI，问时说清"我试了什么、卡在哪一步"
2. **先伪代码后代码**：任何超过 20 行的函数，先写 3–5 步伪代码/注释骨架再填代码
3. **自查清单**（写完每个函数过一遍）：
   - [ ] 循环边界对不对（`p != head`？`i < len`？）
   - [ ] 空表 / 单节点 / 表尾特殊位置处理了吗
   - [ ] 该解引用的指针解了吗
   - [ ] 变量初始化了吗、循环里更新了吗（i++ 漏了吗）
   - [ ] 返回值被使用了吗、有意义吗
   - [ ] 注释和代码一致吗（改代码必改注释）
4. **拉长 AI 检查间隔**：写完 2–3 个函数再让 AI 看一次，中间自己用打印输出排查
5. **防遗忘机制**：复习日默写当周核心代码（凭记忆重写 → 对照 → 差异进笔记）；每周画一页"结构地图"（怎么连、增删改查复杂度、和上周学的区别）
